## ✨ Features

- 📄 Automatic character pagination
- 🎮 Works with the default IKEMEN GO screenpack
- 🔧 No engine recompilation required
- 🧩 Lua-based implementation
- ⚡ Designed for large character rosters
- 🔄 Optional feature, can be enabled or disabled

## 📦 Installation

1. Download `pagedselect.lua`.
2. Copy the file to:

```
external/mods/pagedselect.lua
```

3. Start IKEMEN GO.

No engine modification or recompilation is required.
